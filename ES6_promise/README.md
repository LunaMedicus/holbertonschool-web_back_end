# ES6 Promises

This project covers ES6 Promises in JavaScript, including:

- Creating and using Promises
- The `then`, `resolve`, `catch` methods
- `Promise.all`, `Promise.race`, `Promise.allSettled`
- `throw` / `try` / `catch`
- The `await` operator
- `async` functions

## Requirements

- Node 20.x.x
- npm 9.x.x
- Ubuntu 20.04 LTS

## Setup

```bash
npm install
```

## Tasks

0. **Keep every promise you make and only make promises you can keep** - Return a Promise.
1. **Don't make a promise...if you know you can't keep it** - Resolve or reject based on a boolean.
2. **Catch me if you can!** - Append handlers to a promise.
3. **Handle multiple successful promises** - Use `Promise.all`.
4. **Simple promise** - Return a resolved promise with an object.
5. **Reject the promises** - Return a rejected promise.
6. **Handle multiple promises** - Use `Promise.allSettled`.
7. **Load balancer** - Use `Promise.race`.
8. **Throw an error** - Throw on division by zero.
9. **Throw error / try catch** - Guardrail pattern with try/catch.
