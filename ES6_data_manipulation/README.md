# ES6 Data Manipulation

This project covers ES6 data manipulation techniques in JavaScript, including:

- Using `map`, `filter`, and `reduce` on arrays
- Typed arrays
- The Set, Map, and WeakMap data structures

## Requirements

- Node 20.x.x
- npm 9.x.x
- Ubuntu 20.04 LTS

## Setup

```bash
npm install
```

## Tasks

0. **Basic list of objects** - Create a function that returns an array of student objects.
1. **More mapping** - Use `map` on an array of objects.
2. **Filter** - Use `filter` on an array of objects.
3. **Reduce** - Use `reduce` on an array of objects.
4. **Combine** - Combine `map`, `filter`, and `reduce`.
5. **Typed Arrays** - Create a typed array.
6. **Set data structure** - Work with the Set data structure.
7. **More Set data structure** - Advanced Set operations.
8. **Map data structure** - Work with the Map data structure.
9. **More Map data structure** - Advanced Map operations.
10. **WeakMap data structure** - Work with WeakMap.
